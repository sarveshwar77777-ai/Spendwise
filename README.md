# SpendWise — Student Expense Manager 🎓💳

> **Project Context**: SpendWise is a student-focused expense management prototype created as part of a Design Thinking project (**Project Better Tomorrow – Pathway B: Fresh Discovery Track**). The application is designed to help college students record, understand, and manage their everyday spending.

---

## ✨ Features

- 📊 **Dynamic Dashboard**: Time-based greeting, live spending overview charts (Recharts), category split donut visuals, and summary cards.
- ➕ **Add Expense Form**: Log transactions with Amount (>0), Description, Category, Date, and Payment Method (**UPI**, **Cash**, **Card**, **Other**).
- 📜 **Expense History**: Full searchable, filterable, and sortable table with inline edit and delete capabilities.
- 🎯 **Budget Management**: Set global monthly budget caps and individual category limits with positive, non-fear-based status badges.
- 💡 **Data-Driven Insights**: Automated analytics calculated strictly from stored expenses (highest spending category, 7-day spending, daily average, top 3 categories).
- 🤖 **SpendWise AI (Prototype)**: Interactive chat interface allowing natural language queries powered by local analytical logic.
- ⚙️ **Settings & Preferences**: Currency picker (₹, $, €, £), Light/Dark theme toggle, Demo Data loader, and clear data controls.
- 🔒 **Privacy First**: All data is stored locally in the browser (`localStorage`). No external backend, passwords, or credentials required.

---

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS
- **Icons**: `lucide-react`
- **Charts**: `recharts`
- **Storage**: Browser `localStorage`

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm / yarn / pnpm

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sarveshwar77777-ai/Spendwise.git
   cd Spendwise
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
